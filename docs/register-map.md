# ACM-HEX8 AXI4-Lite 寄存器说明

本文对应 `xiaomeige.com:ip:acm_hex8_axi:1.0`，当前打包修订号为 14。

## 总线属性

- 协议：AXI4-Lite
- 数据宽度：32 位
- 地址宽度：6 位
- 时钟：50 MHz
- 最小地址空间：64 字节
- 字节写使能：支持 `WSTRB`
- 未定义地址：读返回 0，写操作忽略

除特别说明外，保留位读取值不作接口保证，软件应写 0。

## 寄存器表

| 偏移 | 名称 | 访问 | 复位值 | 说明 |
| --- | --- | --- | --- | --- |
| `0x00` | `CONTROL` | R/W | `0x00000001` | 显示控制 |
| `0x04` | `SCAN_DIV` | R/W | `6250` | 位选切换分频 |
| `0x08` | `SERIAL_DIV` | R/W | `25` | 74HC595 串行时钟半周期分频 |
| `0x0C` | `BRIGHTNESS` | R/W | `255` | 全局亮度，只有低 8 位有效 |
| `0x10` | `SEG0_3` | R/W | `0x00000000` | 逻辑位 0～3 的段码 |
| `0x14` | `SEG4_7` | R/W | `0x00000000` | 逻辑位 4～7 的段码 |

### CONTROL — `0x00`

| 位 | 名称 | 说明 |
| --- | --- | --- |
| 0 | `ENABLE` | 1：显示；0：关闭全部位选 |
| 31:1 | Reserved | 软件写 0 |

关闭显示不会清除段码、分频或亮度寄存器。

### SCAN_DIV — `0x04`

当 `SCAN_DIV >= 2` 时：

```text
位选切换频率 = 50 MHz / SCAN_DIV
完整八位刷新率 = 50 MHz / (SCAN_DIV × 8)
```

默认值 6250 对应 8 kHz 位选切换和 1 kHz 完整刷新。写入 0 或 1 时，硬件按
最小分频处理；正常应用建议写入不小于 2 的值。

### SERIAL_DIV — `0x08`

仅串行模式使用：

```text
SCLK = 50 MHz / (2 × SERIAL_DIV)
```

默认值 25 对应 1 MHz。写入 0 或 1 时，硬件按最小分频处理。

### BRIGHTNESS — `0x0C`

低 8 位为全局亮度：

- `0`：全灭；
- `1～254`：PWM/脉冲密度调制；
- `255`：最大亮度。

并行模式采用 8 位 PWM；串行模式采用逐位脉冲密度调制。亮度设置不改变
`SCAN_DIV` 决定的完整刷新率。

### SEG0_3 / SEG4_7 — `0x10` / `0x14`

每个字节对应一个逻辑数码管，逻辑位 0 是最左侧，逻辑位 7 是最右侧：

```text
SEG0_3[7:0]   = digit 0
SEG0_3[15:8]  = digit 1
SEG0_3[23:16] = digit 2
SEG0_3[31:24] = digit 3
SEG4_7[7:0]   = digit 4
SEG4_7[15:8]  = digit 5
SEG4_7[23:16] = digit 6
SEG4_7[31:24] = digit 7
```

每字节段码格式：

```text
bit7 bit6 bit5 bit4 bit3 bit2 bit1 bit0
 DP    G    F    E    D    C    B    A
```

软件寄存器使用高电平有效段码。常用数字：

| 字符 | 段码 | 字符 | 段码 |
| --- | --- | --- | --- |
| 0 | `0x3F` | 5 | `0x6D` |
| 1 | `0x06` | 6 | `0x7D` |
| 2 | `0x5B` | 7 | `0x07` |
| 3 | `0x4F` | 8 | `0x7F` |
| 4 | `0x66` | 9 | `0x6F` |

小数点通过段码与 `0x80` 按位或得到，例如 `2.` 为 `0xDB`。

## `12.345678` 写入示例

假设 IP 基地址为 `BASE`：

```text
write BASE + 0x00 = 0x00000000  # 更新期间关闭显示
write BASE + 0x04 = 0x0000186A  # 6250
write BASE + 0x08 = 0x00000019  # 25
write BASE + 0x0C = 0x000000FF  # 最大亮度
write BASE + 0x10 = 0x664FDB06  # 1, 2., 3, 4
write BASE + 0x14 = 0x7F077D6D  # 5, 6, 7, 8
write BASE + 0x00 = 0x00000001  # 开启显示
```
